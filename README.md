# Conduta H. pylori

Apoio à decisão para erradicação do *H. pylori* baseado no V Consenso Brasileiro sobre a Infecção por *H. pylori* (Arq Gastroenterol 2026;63:e26043).

Ferramenta para uso pessoal; não substitui o julgamento clínico. Nenhum dado de paciente sai do navegador.

Ao publicar uma versão nova, suba `VERSAO` em `sw.js`.
